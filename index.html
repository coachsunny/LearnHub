GUIDE

如何在 LearnHub 新增您的 HTML 上課教材？

步驟 1：放入您的 HTML 教材檔案

將製作好的 .html 教材放入 materials/分類資料夾/ 下（也可直接複製 materials/template.html 標準模板來編寫新講義）。

步驟 2：在設定檔登記教材資訊

打開 js/materials-data.js，在 materials 陣列加入一筆資料即可自動出現在網站上：

{
  id: "my-new-lesson",
  title: "Ch.03 響應式網頁 Grid 網格系統實戰",
  category: "web-dev",
  description: "深入淺出介紹 CSS Grid 二維排版技巧與實務案例。",
  path: "materials/web-dev/grid-layout.html",
  date: "2026-10-21",
  duration: "50 分鐘",
  level: "進階",
  tags: ["CSS3", "Grid", "RWD"]
}

步驟 3：推送至 GitHub 自動部署 Cloudflare

執行 git add . && git commit -m "新增教材" && git push，Cloudflare 即會自動同步更新線上教材網站。
