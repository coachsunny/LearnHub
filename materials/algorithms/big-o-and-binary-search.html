Lec 01 時間複雜度 Big-O 與二分搜尋法實戰

當資料量從 100 筆成長到 1,000 萬筆時，如何透過對數時間複雜度 O(log n) 瞬間完成搜尋？

本節課學習目標

  • 理解漸進時間複雜度 $O(1)$、$O(\log n)$、$O(n)$ 與 $O(n^2)$ 的成長趨勢差異
  • 掌握二分搜尋法 (Binary Search) 的前提條件與閉區間 [left, right] 寫法

1 二分搜尋法標準實作 (Python)

對於已排序的陣列，每次比較中間元素即可排除一半的搜尋範圍：

def binary_search(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
⚠️ 常見邊界陷阱

在強型別語言（如 C++ / Java）中，計算中點建議寫成 left + (right - left) / 2，可避免 left + right 超過整數上限而發生溢位 (Overflow)。
