Ch.02 JavaScript DOM 操作與事件委派機制

深入理解事件冒泡 (Event Bubbling) 與事件委派 (Event Delegation)，寫出高效能的動態網頁互動程式。

本節課學習目標

  • 使用 querySelector 與 querySelectorAll 精準選取 DOM 節點
  • 理解瀏覽器事件傳遞三階段：捕獲階段、目標階段、冒泡階段
  • 透過父元素統一監聽子元素事件（Event Delegation），減少記憶體消耗

1 為什麼需要事件委派？

當清單中有 100 個按鈕，甚至會有動態新增的項目時，若對每個按鈕個別綁定 addEventListener，不僅耗費記憶體，動態新增的按鈕也不會有反應。透過事件冒泡機制，我們只需在父層容器綁定一次監聽器：

const todoList = document.querySelector('#todo-list');

todoList.addEventListener('click', (event) => {
  const deleteBtn = event.target.closest('.btn-delete');
  if (!deleteBtn) return;

  const item = deleteBtn.closest('li');
  item.remove();
});

2 常見 DOM 選取與操作方法對照

API 方法 回傳值型別 實務用途說明
document.querySelector(sel) Element | null 取得第一個符合 CSS 選擇器的元素
element.closest(sel) Element | null 由當前元素往上尋找符合選擇器的最近祖先元素（事件委派必備）
element.classList.toggle(cls) boolean 切換指定 CSS 類別，回傳切換後是否包含該類別
