Ch.01 現代 CSS Flexbox 彈性盒子完全指南

掌握主軸 (Main Axis) 與交錯軸 (Cross Axis) 的空間分配邏輯，輕鬆完成各式響應式元件排版。

本節課學習目標

  • 理解 Flex Container（外容器）與 Flex Items（內元件）的關係
  • 熟練操作 justify-content 與 align-items 進行水平與垂直對齊
  • 認識 flex-grow、flex-shrink 與 flex-basis 彈性縮放機制

1 什麼是 Flexbox 模型？

當我們在父元素設定 display: flex; 時，該元素會成為 Flex 外容器 (Container)，而其直接子元素則自動成為 Flex 內元件 (Items)。預設情況下，子元素會沿著水平主軸由左至右排列。

.nav-container {
  display: flex;
  justify-content: space-between; /* 主軸分散對齊 */
  align-items: center;            /* 交錯軸置中對齊 */
  gap: 16px;                      /* 元件間距 */
}

💡 課堂實務技巧

過去在 CSS 要達成「水平垂直完全置中」非常繁瑣，現在只需在外容器加上 display: flex; justify-content: center; align-items: center; 三行即可完成！

3 隨堂問答檢核

Q1：如果把 flex-direction 改為 column，主軸 (Main Axis) 的方向會變成什麼？

當設定為 flex-direction: column 時，主軸會改為由上到下的垂直方向，此時 justify-content 控制的是垂直分佈，而 align-items 則改為控制水平對齊。
