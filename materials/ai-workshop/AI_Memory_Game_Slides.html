🐙 認識 GitHub：小程式的雲端家園與快速就緒

電腦裡的檔案只有自己看得到，放在 GitHub 雲端才能讓全世界連線暢玩！

🌐 什麼是 GitHub 與倉庫（Repository）？
  • GitHub 是什麼？ 全球最大的程式碼雲端硬碟，負責替我們免費保管網頁檔案。
  • 什麼是倉庫（Repository / Repo）？ 就像雲端硬碟裡的一個「專案資料夾」，等等我們會把 index.html 放進專屬倉庫。
  • 什麼是 GitHub Pages？ GitHub 提供的免費伺服器服務，30 秒內把 HTML 轉成正式公開網址！
🔑 快速註冊與登入指引

STAGE 4: MOBILE APP

📱 把遊戲裝進手機主畫面（專屬 App）

不用到 App Store 下載！現場掃描 QR Code，一鍵變成手機桌面圖示

🍏 蘋果 iPhone (Safari 瀏覽器)
第一步：開啟 Safari 瀏覽器打開遊戲網址。
第二步：點擊螢幕下方正中間的「分享按鈕（方形箭頭向上 ⬆️）」。
第三步：選單往下滑，點選「加入主畫面（Add to Home Screen）➕」。
第四步：點選右上角「新增」，桌面立刻出現專屬小圖示！
🤖 安卓 Android (Chrome 瀏覽器)
第一步：用 Chrome 瀏覽器打開遊戲網址。
第二步：點擊螢幕右上角的「三個直排小圓點選單 ⋮」。
第三步：點選「加到主畫面」或「安裝應用程式」。
第四步：確認新增，手機桌布上立刻擁有一款自製 App！
點擊手機桌面的圖示，遊戲會全螢幕啟動，完全就像市面上賣的益智遊戲一樣流暢！
