1 常用 Git 指令速查表

# 1. 初始化專案並綁定帳號信箱
git init
git config user.email "lee.shunyi@gmail.com"

# 2. 將修改加入暫存區並建立版本提交
git add .
git commit -m "feat: 新增課程 HTML 教材"

# 3. 推送至 GitHub 遠端儲存庫（自動觸發 Cloudflare 部署）
git push -u origin main
