Unit 01 Python 四大核心容器：List、Tuple、Dict 與 Set

掌握可变與不可變資料結構差異，選對容器讓程式可讀性與執行效率倍增。

本節課學習目標

  • 分辨有序與無序、可變 (Mutable) 與不可變 (Immutable) 容器
  • 運用字典 (Dict) 達成 $O(1)$ 快速鍵值查找
  • 學會 Pythonic 的列表推導式 (List Comprehension)

1 四大容器特性總整理

容器型別 語法範例 可變性 重複元素 典型使用場景
List (串列) [10, 20, 30] 可變 允許 需要依序儲存且經常增刪的集合
Tuple (元組) (10, 20, 30) 不可變 允許 固定座標、函式多回傳值、保護資料不被修改
Dict (字典) {"id": 1, "name": "Amy"} 可變 Key 唯一 鍵值對應查找、JSON 資料結構處理
Set (集合) {10, 20, 30} 可變 自動去重 快速去除重複值、交集/聯集/差集運算

2 列表推導式 (List Comprehension)

將傳統多行迴圈濃縮為一行高可讀性的敘述：

# 篩選出偶數並計算平方值
numbers = [1, 2, 3, 4, 5, 6, 7, 8]
even_squares = [n ** 2 for n in numbers if n % 2 == 0]
print(even_squares)  # 輸出: [4, 16, 36, 64]
